Riddim Machine for Windows

Standalone: open the Standalone folder and double-click "Riddim Forge.exe",
"Riddim Machine.exe" or "Riddim Machine FX.exe". No install needed.
Pick your audio and MIDI devices from the Options button at the top left.

VST3: copy the .vst3 folders from the VST3 folder into
C:\Program Files\Common Files\VST3
then rescan plugins in your DAW.

Riddim Forge's visual uses projectM-4.dll (MilkDrop scenes on your graphics card).
Keep it next to "Riddim Forge.exe" and inside "Riddim Forge.vst3" where it already is.
